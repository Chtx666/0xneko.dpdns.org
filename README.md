## 🚀 本地執行

複製儲存庫：

```bash
git clone https://github.com/Chtx666/blog.git
cd blog
```

安裝依賴：

```bash
npm install
```

啟動開發伺服器：

```bash
npm run dev
```

建置：

```bash
npm run build
```
