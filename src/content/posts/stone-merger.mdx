## 原題

<div style="border:1px solid #ccc; padding:10px;">
# P1880 [NOI1995] 石子合并

## 题目描述

在一个圆形操场的四周摆放 $N$ 堆石子，现要将石子有次序地合并成一堆，规定每次只能选相邻的 $2$ 堆合并成新的一堆，并将新的一堆的石子数，记为该次合并的得分。

试设计出一个算法，计算出将 $N$ 堆石子合并成 $1$ 堆的最小得分和最大得分。

## 输入格式

数据的第 $1$ 行是正整数 $N$，表示有 $N$ 堆石子。

第 $2$ 行有 $N$ 个整数，第 $i$ 个整数 $a_i$ 表示第 $i$ 堆石子的个数。

## 输出格式

输出共 $2$ 行，第 $1$ 行为最小得分，第 $2$ 行为最大得分。

## 输入输出样例 #1

### 输入 #1

```
4
4 5 9 4
```

### 输出 #1

```
43
54
```

## 说明/提示

$1\leq N\leq 100$，$0\leq a_i\leq 20$。
</div>

## 綫性

注意到題目較為複雜，可化繁為簡：

捨棄“圓形操場”的條件，先考慮“線性跑道”，

f[i][j]: 将区间i～j合并为一堆的最小代价（很好動態規劃使我的得分旋轉

在狀態設計之後，我們可以使用區間枚舉O(n^2)*分割點枚舉O(n)，最後套轉移方程：

設p[]為原石子數數組的前綴和數組，則

f[left][right]=min(f[left][right],f[left][k]+f[k+1][right]+p[right]-p[left-1]);

即可得到最小值代碼：

```cpp
for (int i = 1; i <= n; i++) { // 遍历每一堆
    cin >> a[i]; // 读取第 i 堆的质量
    p[i] = p[i - 1] + a[i]; // 维护前缀和 p[i]
}
memset(f, 0x7f, sizeof(f)); // 将 f 初始化为大数（表示无穷）
for (int i = 0; i <= n; i++) // 对角线 f[i][i] = 0
    f[i][i] = 0; // 单个堆合并代价为 0
for (int len = 2; len <= n; len++) { // 枚举区间长度 len
    for (int i = 1; i + len - 1 <= n; i++) { // 枚举区间左端点 i
        int left = i; // 区间左端
        int right = i + len - 1; // 区间右端
        for (int k = left; k < right; k++) // 枚举分割点 k
            f[left][right] = min(f[left][right], f[left][k] + f[k + 1][right] + p[right] - p[left - 1]); // 状态转移：左右合并并加上区间和
    }
}
```

## 劃歸

接下來考慮環形，最好的方法（我懶）就是利用劃歸思想，
在數組後再接一個copy的相同數組，即可覆蓋環形的任意情況。

注意事項：

1.需加倍所有數組範圍大小；

2.枚舉時最大長度為n，也即左端點在原數組上；

3.注意初始化情況。

代碼如下：

```cpp
memset(f, 0x7f, sizeof(f));
for (int i = 0; i < n * 2; i++)
    f[i][i] = 0; // 单个堆合并代价为 0
for (int len = 2; len <= n; len++) { // 枚举区间长度 len
    for (int i = 1; i <= 2 * n - len + 1; i++) { // 枚举区间左端点 i
        int left = i; // 区间左端
        int right = i + len - 1; // 区间右端
        for (int k = left; k < right; k++) // 枚举分割点 k
            f[left][right] = min(f[left][right], f[left][k] + f[k + 1][right] + p[right] - p[left - 1]);
    }
}
int mini = 0x7f7f7f7f;
for (int i = 1; i <= n; i++)
    mini = min(mini, f[i][n + i - 1]);
cout << mini << endl;
```

## 答案

最大值同理，僅需注意初始化條件；

相信聰明的你一定看懂了吧【喜】

最終AC代碼：

```cpp
#include <cstring>
#include <iostream>
using namespace std;

int n;
int a[701], p[701]; // a[i]: 第 i 堆质量, p[i]: 前缀和
int f[701][701]; // f[i][j]: 将区间 i..j 合并为一堆的最小代价

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        p[i] = p[i - 1] + a[i]; // 维护前缀和 p[i]
    }
    for (int i = n + 1; i < 2 * n; i++)
        p[i] = p[i - 1] + a[i - n];

    // 最小值
    memset(f, 0x7f, sizeof(f));
    for (int i = 0; i < n * 2; i++)
        f[i][i] = 0; // 单个堆合并代价为 0
    for (int len = 2; len <= n; len++) { // 枚举区间长度 len
        for (int i = 1; i <= 2 * n - len + 1; i++) { // 枚举区间左端点 i
            int left = i; // 区间左端
            int right = i + len - 1; // 区间右端
            for (int k = left; k < right; k++) // 枚举分割点 k
                f[left][right] = min(f[left][right], f[left][k] + f[k + 1][right] + p[right] - p[left - 1]);
        }
    }
    int mini = 0x7f7f7f7f;
    for (int i = 1; i <= n; i++)
        mini = min(mini, f[i][n + i - 1]);
    cout << mini << endl;

    // 最大值
    memset(f, 0, sizeof(f));
    for (int len = 2; len <= n; len++) { // 枚举区间长度 len
        for (int i = 1; i <= 2 * n - len + 1; i++) { // 枚举区间左端点 i
            int left = i; // 区间左端
            int right = i + len - 1; // 区间右端
            for (int k = left; k < right; k++) // 枚举分割点 k
                f[left][right] = max(f[left][right], f[left][k] + f[k + 1][right] + p[right] - p[left - 1]);
        }
    }
    int maxi = 0;
    for (int i = 1; i <= n; i++)
        maxi = max(maxi, f[i][n + i - 1]);
    cout << maxi << endl;
    return 0;
}
```
