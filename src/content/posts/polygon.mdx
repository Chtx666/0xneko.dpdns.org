# P14360 [CSP-J 2025] 多边形

## 题目描述

小 R 喜欢玩小木棍。小 R 有 $n$ 根小木棍，第 $i$ ($1 \leq i \leq n$) 根小木棍的长度为 $a_i$。

小 X 希望小 R 从这 $n$ 根小木棍中选出若干根小木棍，将它们按任意顺序首尾相连拼成一个多边形。小 R 并不知道小木棍能拼成多边形的条件，于是小 X 直接将条件告诉了他：对于长度分别为 $l_1, l_2, \dots, l_m$ 的 $m$ 根小木棍，这 $m$ 根小木棍能拼成一个多边形当且仅当 $m \geq 3$ 且所有小木棍的长度之和**大于**所有小木棍的长度最大值的两倍，即 $\sum_{i=1}^{m} l_i > 2 \times \max_{i=1}^{m} l_i$。

由于小 R 知道了小木棍能拼成多边形的条件，小 X 提出了一个更难的问题：有多少种选择小木棍的方案，使得选出的小木棍能够拼成一个多边形？你需要帮助小 R 求出选出的小木棍能够拼成一个多边形的方案数。两种方案不同当且仅当选择的小木棍的**下标集合不同**，即存在 $1 \leq i \leq n$，使得其中一种方案选择了第 $i$ 根小木棍，但另一种方案未选择。由于答案可能较大，你只需要求出答案对 $998,244,353$ 取模后的结果。

## 输入格式

输入的第一行包含一个正整数 $n$，表示小 R 的小木棍的数量。

输入的第二行包含 $n$ 个正整数 $a_1, a_2, \dots, a_n$，表示小 R 的小木棍的长度。

## 输出格式

输出一行一个非负整数，表示小 R 选出的小木棍能够拼成一个多边形的方案数对 $998,244,353$ 取模后的结果。

## 思路

這題是2025CSP-J題目，經我賽場實測，深搜暴力應該能拿30分。

多邊形要求可以看成兩個：

1.木棍數量要小於等於3；

2.$\sum_{i=1}^{m} l_i > 2 \times \max_{i=1}^{m} l_i$，即其他所有邊的長度總和要大於最大邊。

對此我們可以想到：

1.對$a$數組進行預處理排序；

2.順序枚舉最大邊，對其前面的所有邊進行DP，統計總和能大於最大邊的方案數。

或許你已經看出來了（或沒有），不管怎樣，01背包模板已經呼之欲出。

那麽，我們應設計DP數組$f$，使$f[i]$表示對於選定最大邊，其前面所有邊能夠達到總和為$i$的方案數。

然而，注意到（依舊注意力驚人），$i∈[0,sum_{i=1}^{n} a_i]$，也就是説加上枚舉的時間複雜度應爲$O(n \times sum_{i=1}^{n} a_i)$，
數據範圍均爲5000，絕對超時。

經過與ChatGPT的探討，我恍然小悟：

透過表象，尋求本心，方能如意。

我們的目的最初是什麽？

是篩選出前面總和大於最大邊的邊。

如果前面一條邊已經大於$max(a_i)$，便統統不用區分，乾脆歸到$max(a_i)+1$上，即5001上即可。

只需判斷解決。

代碼如下。

## 滿分代碼

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

#define int long long

const int MOD = 998244353;

int n;
int a[5010];
int f[5010];
int ans;

signed main() {
    cin >> n;
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    sort(a + 1, a + n + 1);
    f[0] = 1;
    for (int i = 1; i < n; i++) {
        for (int j = 5001; j >= 0; j--)
            f[min(5001LL, j + a[i])] = (f[min(5001LL, j + a[i])] + f[j]) % MOD;
        for (int j = 5001; j > a[i + 1]; j--)
            ans = (ans + f[j]) % MOD;
    }
    cout << ans << endl;
    return 0;
}
```
